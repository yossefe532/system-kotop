\# AI Project Context



\## Project Name



EduCore Academy Management Platform



\---



\## Purpose



This project is an Academy Management Platform.



It is NOT only a Point of Sale system.



The Student is the central entity.



Everything revolves around students.



\---



\## Tech Stack



Backend:

\- FastAPI

\- SQLAlchemy

\- PostgreSQL

\- Alembic



Frontend:

\- React

\- Vite



Offline:

\- IndexedDB



Authentication:

\- JWT

\- RBAC



\---



\## Rules



Never rewrite existing code.



Always extend existing implementation.



Maintain backward compatibility.



Do not duplicate logic.



Always inspect the existing implementation before adding new features.



Never break API contracts.



Never remove existing functionality.



\---



\## Coding Standards



\- Modular architecture

\- Small reusable components

\- Service layer

\- Repository pattern where appropriate

\- Proper error handling

\- Production quality only



\---



\## Current Goal



Build a complete Student CRM.



The Student becomes the core entity.



The CRM must support future integration with:



\- Inventory

\- POS

\- Finance

\- Courses

\- Attendance

\- Certificates

\- Events

\- WhatsApp

\- Notifications



\---



\## AI Workflow



Before implementing any feature:



1\. Audit existing implementation.

2\. Reuse existing code.

3\. Extend only missing functionality.

4\. Preserve compatibility.

5\. Update tests.

6\. Document changes.



Never generate duplicate systems.
